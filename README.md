# Hangman Game (x86 Assembly)

A console-based Hangman game developed in x86 Assembly Language using EMU8086.

## Features
- Interactive keyboard input and character handling
- String matching and score tracking
- Built using procedures, loops, and DOS interrupts (INT 21h)

## Project Files
- `*.asm` - Assembly source code
- `*.docx` - Complete project report
- `*.mp4` - Video demonstration
